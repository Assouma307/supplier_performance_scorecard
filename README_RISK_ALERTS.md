# Risk Alerts — guide d’utilisation

Les alertes sont détectées lors du recalcul d’une fiche d’évaluation et par une tâche planifiée quotidienne.

Règles principales :
- score inférieur à 50 : alerte critique ;
- score inférieur à 70 : alerte élevée ;
- baisse d’au moins 15 points entre deux évaluations : alerte de dégradation ;
- au moins 3 réceptions en retard parmi les 5 dernières réceptions évaluables : alerte de retards répétés.

Les alertes de score et de retards répétés sont clôturées automatiquement lorsque leur condition n’est plus remplie. Les alertes de dégradation restent ouvertes jusqu’à leur clôture par un utilisateur. Les données insuffisantes sont mentionnées dans la description de l’alerte lorsque le score déclenche un seuil.
