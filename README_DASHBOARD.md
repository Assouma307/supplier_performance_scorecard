# Dashboard — guide d’utilisation

Le tableau de bord affiche les indicateurs de la société courante :
- nombre de fournisseurs et de fiches évalués ;
- score global moyen, ponctualité moyenne et taux de réceptions à temps ;
- répartition des niveaux de risque et nombre de fiches avec données insuffisantes ;
- nombre d’alertes en cours, élevées et critiques.

Les raccourcis ouvrent les fiches d’évaluation, les analyses, l’historique et les alertes. Les actions appliquent un filtre sur la société courante.

Les indicateurs résument les dernières fiches enregistrées. Pour actualiser les scores et déclencher la détection des risques, recalculer les fiches d’évaluation. Le tableau de bord ne recalcule pas lui-même les scores.
